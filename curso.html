O que é o Terminal?

1.1 Os três conceitos essenciais

Muita gente confunde esses termos. Entender a diferença é o primeiro passo.

TermoO que éAnalogia
TerminalO programa (janela) onde você digitaO microfone que você fala
ShellO "cérebro" que interpreta os comandosO ouvido que entende o que você falou
Linha de ComandoA forma de interagir (digitando texto)A língua que você está falando
Resumo: Você digita no terminal, a shell entende, o sistema executa.

1.2 Shells mais comuns

ShellSistemaObservação
PowerShellWindowsUsada neste curso
BashLinux / MacMais usada no mundo profissional
ZshmacOS (padrão)Extensão do Bash

1.3 Terminal vs Interface Gráfica

Interface Gráfica (GUI)Terminal (CLI)
Clica em ícones e janelasDigita comandos de texto
Intuitiva para iniciantesCurva de aprendizado maior
Mais lenta para tarefas repetitivasMuito mais rápida para automação
Difícil de usar remotamenteIdeal para acesso remoto (SSH)
Importante: As duas abordagens são complementares, não rivais. Profissionais de tecnologia usam as duas.

1.4 Como abrir o terminal no Windows

Pressione Win + R, digite um dos comandos abaixo e pressione Enter:

Windows – atalhos de abertura # Opção 1 – PowerShell powershell # Opção 2 – Prompt de Comando (mais antigo) cmd # Opção 3 – Windows Terminal (app moderno) wt

Navegação Básica

2.1 Estrutura de pastas e arquivos

Todo sistema organiza informações em uma hierarquia de pastas (diretórios) e arquivos.

Documentos/ ├── Projetos/ │ ├── site.html │ └── app.js └── Notas.txt

No terminal, você navega por essa estrutura com comandos em vez de clicar.

2.2 pwd — Onde estou?

Exibe o caminho completo da pasta onde você está agora.

Exemplo PS C:\Users\luizh\Documents> pwd Path ---- C:\Users\luizh\Documents
Dica: Use pwd sempre que estiver perdido e quiser saber onde está.

2.3 ls — Ver o conteúdo da pasta

Lista todos os arquivos e pastas dentro do diretório atual.

Exemplo PS C:\Users\luizh\Documentos\projetos> ls Directory: C:\Users\luizh\Documentos\projetos Mode LastWriteTime Length Name ---- ------------- ------ ---- la--- 10/09/2023 21:13 1259 imc.js la--- 10/09/2023 20:54 896 index.html la--- 27/09/2023 10:00 1584 style.css

2.4 cd — Entrar em uma pasta

cd significa change directory (mudar de diretório).

Entrar em uma pasta PS C:\Users\luizh\OneDrive> cd Documentos PS C:\Users\luizh\OneDrive\Documentos>
Voltar uma pasta (..) = pasta acima PS C:\Users\luizh\OneDrive\Documentos> cd .. PS C:\Users\luizh\OneDrive>
Ir para a pasta do usuário (~) PS C:\Users\luizh\OneDrive> cd ~ PS C:\Users\luizh>

2.5 Caminhos Absolutos vs Relativos

TipoExemploQuando usar
Absoluto C:\Users\Luiz\Documentos Funciona de qualquer lugar; começa sempre pela raiz
Relativo cd Documentos Depende de onde você está agora; mais curto de digitar
Regra prática: Se já estiver em C:\Users\Luiz, você pode usar cd Documentos em vez de digitar o caminho completo.
✏️ Exercício Prático — Navegação
  1. Abra o terminal e execute pwd para ver onde você está.
  2. Execute ls para listar o conteúdo da pasta atual.
  3. Entre em alguma pasta com cd nome_da_pasta.
  4. Execute pwd novamente para confirmar onde está.
  5. Volte com cd .. e confirme com pwd.
  6. Vá direto para sua pasta de usuário com cd ~.
3

Criando Coisas

3.1 mkdir — Criar pastas

mkdir significa make directory (criar diretório).

Criar uma pasta PS C:\Users\luizh\Documentos> mkdir terminal Directory: C:\Users\luizh\Documentos Mode LastWriteTime Length Name ---- ------------- ------ ---- d---- 24/02/2026 13:12 terminal
Criar várias pastas de uma vez PS ...> mkdir src assets docs

3.2 New-Item — Criar arquivos (PowerShell)

No PowerShell, o comando para criar arquivos vazios é New-Item.

Criar um arquivo PS C:\...\terminal> New-Item arquivo.txt Directory: C:\Users\luizh\Documentos\terminal Mode LastWriteTime Length Name ---- ------------- ------ ---- -a--- 24/02/2026 13:17 0 arquivo.txt
Criar vários arquivos de uma vez PS ...> New-Item index.html style.css app.js
Diferença importante: mkdir cria pastas. New-Item cria arquivos.
✏️ Exercício Prático — Criando
  1. Navegue até sua pasta de Documentos com cd ~/Documents.
  2. Crie uma pasta chamada meu-projeto com mkdir meu-projeto.
  3. Entre nela: cd meu-projeto.
  4. Crie os arquivos New-Item index.html style.css.
  5. Confirme com ls que tudo foi criado.
4

Gerenciando Arquivos

4.1 cp — Copiar arquivos

Cria uma cópia de um arquivo ou pasta. O original continua existindo.

Sintaxe cp origem destino
Exemplos # Copiar no mesmo lugar (novo nome) cp arquivo.txt copia.txt # Copiar para outra pasta cp arquivo.txt Documentos/

4.2 mv — Mover ou renomear

Move um arquivo para outro lugar ou muda seu nome (o original deixa de existir).

Mover para outra pasta mv arquivo.txt Documentos/
Renomear arquivo mv copia.txt novo_nome.txt

4.3 rm — Remover arquivos

⚠️ Atenção: Arquivos removidos com rm no terminal não vão para a Lixeira. São excluídos permanentemente.
Remover um arquivo rm arquivo.txt
Remover múltiplos arquivos rm arquivo1.txt arquivo2.txt

4.4 Remover pastas

Pastas não podem ser removidas com rm simples — é preciso usar o parâmetro -r (recursivo).

Remover uma pasta e todo seu conteúdo rm -r nome_da_pasta
⚠️ Cuidado redobrado: rm -r apaga a pasta e tudo dentro dela de forma irrecuperável.
✏️ Exercício Prático — Gerenciando
  1. Dentro de meu-projeto, copie o index.html: cp index.html backup.html.
  2. Renomeie o backup: mv backup.html index-v1.html.
  3. Confirme com ls.
  4. Remova o arquivo renomeado: rm index-v1.html.
  5. Crie uma pasta mkdir testes e depois remova-a: rm -r testes.
5

Lendo Arquivos

5.1 cat — Ver o conteúdo completo

Exibe todo o conteúdo de um arquivo direto no terminal.

Exemplo PS ...> cat package.json { "name": "meu-projeto", "version": "1.0.0", ... }
Quando usar: Ideal para arquivos pequenos que cabem na tela. Para arquivos grandes, use os comandos abaixo.

5.2 Get-Content -Head — Ver as primeiras linhas

Mostra apenas o começo do arquivo. Útil para ver o início de logs ou arquivos grandes.

Ver as primeiras 10 linhas PS ...> Get-Content package.json -Head 10 { "name": "meu-projeto", "version": "1.0.0", ... }

5.3 Get-Content -Tail — Ver as últimas linhas

Mostra apenas o fim do arquivo. Muito usado para acompanhar logs em tempo real.

Ver as últimas 10 linhas PS ...> Get-Content package.json -Tail 10
✏️ Exercício Prático — Lendo Arquivos
  1. Crie um arquivo de texto com algum conteúdo (pode ser pelo bloco de notas).
  2. Use cat nome_do_arquivo.txt para ver o conteúdo.
  3. Use Get-Content nome_do_arquivo.txt -Head 5 para ver as 5 primeiras linhas.
  4. Use Get-Content nome_do_arquivo.txt -Tail 5 para ver as 5 últimas.
